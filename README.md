# 🐾 上網寵浪 - 動物領養管理系統 

## 專案簡介
「上網寵浪」是一個動物領養管理系統資料庫設計專案 。本系統旨在讓使用者透過條件篩選尋找適合的寵物，同時協助管理人員處理審核流程、記錄寵物健康與疫苗施打狀況，藉此提升寵物找到適合主人的成功率與員工的管理效率 。

**開發團隊**：江芷瑜、陳思妤、今村雛乃 

---

## 系統功能說明

系統主要分為「前端使用者（領養人）」與「後端管理員（平台員工）」兩大模組 ：

### 前端使用者功能 (領養人)
* **會員註冊與身分驗證**：提供使用者建立帳號、修改個人資料及聯絡資訊 。
* **寵物查詢與篩選機制**：允許使用者根據特定屬性（如：種類、性別、領養狀態等）進行多條件查詢 。
* **領養申請**：使用者可針對特定「待領養」狀態的寵物提出線上申請，並能查看領養狀態（待領養、已領養）及健康狀態 。

### 後端管理員功能 (平台員工)
* **寵物資料與狀態管理**：新增寵物檔案，更新寵物當前狀態（如：待領養、已領養），並可上傳照片 。
* **健康與醫療紀錄追蹤**：記錄每隻寵物的疫苗施打狀況 。

## 資料需求與實體說明

* **Member (會員 / 領養人)**：記錄平台註冊會員與領養人的基本資料（包含姓名、地址、電話、Email 等） 。
* **Pet (寵物)**：記錄待領養寵物的詳細檔案（如品種、年齡、性別）與即時狀態（如待領養 / 已領養、疫苗狀態、照片等） 。
* **Adoption_Application (領養申請單)**：記錄會員提出領養毛孩的申請表單紀錄與當前審核狀態 。
* **Employee (員工 / 管理員)**：記錄負責管理系統與審核領養業務的內部人員資料 。
* **Review (審核紀錄)**：關聯實體，用於記錄哪位員工負責審核了哪一張領養申請單，以解決多對多關聯問題 。
* **HealthRecord (健康紀錄)**：依附於寵物實體的弱實體，記錄醫療行為（如結紮手術、狂犬病疫苗）與執行日期 。
